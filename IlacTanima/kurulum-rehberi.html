Sistemin Kısaca Ne Yaptığı
1. Pi, AI kameradan canlı görüntü alır.
2. YOLO + OCR + barkod ile "Parol" kutusunu bulur ve görüntüdeki konumunu hesaplar.
3. İki VL53L4CD ToF sensörü hedefe olan sol ve sağ mesafeyi milimetre hassasiyetle ölçer.
4. Pi bu bilgileri değerlendirir: "Kutu sağda → sola dön", "Mesafe 200mm → 5cm daha yaklaş", "Sol-sağ fark 8mm → düzelt".
5. Arduino'ya USB üzerinden servo komutları gönderir: 3 110, 5 180.
6. Arduino servo'ları sürer → robot kol harekete geçer → gripper kapanır → kutu alınır.

Pi'ye İşletim Sistemi Kur

MicroSD karta Raspberry Pi OS yazılacak — yaklaşık 10 dakika

📥
Önce Raspberry Pi Imager'ı indir ve kur Adres: raspberrypi.com/software → "Download for Windows" butonuna tıkla → Kur → Aç
1
MicroSD kartı bilgisayara tak
Kart okuyucuya koy, USB'ye tak. Windows'ta E: veya F: gibi görünür.
2
Raspberry Pi Imager'ı aç — üç şeyi seç
Device  Raspberry Pi 5    OS  Raspberry Pi OS (64-bit)    Storage  MicroSD kartın
3
"Next" demeden önce — Ayarları gir (ÇOK ÖNEMLİ)
Sağ altta çıkan "Edit Settings" düğmesine tıkla, aşağıdaki bilgileri gir:
Hostname : pi5
Username : pi
Password : kendi şifreni yaz (NOT ET — tekrar lazım olacak)
Wi-Fi SSID : evin Wi-Fi adı (telefondaki isim)
Wi-Fi Şifre: Wi-Fi şifren (büyük/küçük harf önemli!)
SSH : Etkinleştir → "Use password authentication"
4
"Save" → "Yes" → Onaya bas → Bekle
5–10 dakika sürer. Kopyalama bitince MicroSD kartı çıkar.
5
MicroSD'yi Pi'nin altına tak, güç ver
İlk açılış 2–3 dakika sürebilir. Pi Wi-Fi'a otomatik bağlanır. Acele etme.
Pi'nin IP'sini Bul
Windows Komut İstemi'nde:
ping pi5.local
Cevap gelince çıkan IP'yi not al:
Reply from 192.168.1.47
PuTTY ile Bağlan (SSH)
PuTTY'yi putty.org'dan indir:
Host: pi5.local
Port: 22
User: pi şifreni yaz
Siyah terminal ekranı = Pi'ye bağlandın!

Kamerayı Fiziksel Bağla

AI Camera (IMX500) CSI flex kablo ile Pi'ye bağlanır

🔴
Önce Pi'yi tamamen kapat, güç kablosunu çek! Güç takılıyken kamera bağlamak Pi'ye ve kameraya zarar verebilir.
1
Pi'yi kapat ve güç kablosunu çek
Güç ışığı sönene kadar bekle.
2
Pi üzerindeki "CAM/DISP 0" girişini bul
Pi 5'te iki kamera girişi var — küçük siyah klipsli konnektörler. "CAM/DISP 0" yazan birini kullan (soldaki).
3
Klipsi hafifçe yukarı kaldır
Konnektörün üstündeki siyah klipsi tırnağınla hafifçe kaldır. Zorla çekme, kırılabilir.
4
Flex kabloyu tak — mavi/metalik taraf DIŞA bakacak
Kabloyu düzgünce sok. Klipsi aşağı bas — "tık" sesi duyulmalı. Kablo dışarı çekilemiyor olmalı.
5
Güç ver — kamera otomatik tanınır
Sürücü kurman gerekmez. Pi OS kamerayı otomatik bulur.
✅
Kamera doğru bağlandı mı kontrol et PuTTY'de şunu yaz:  libcamera-hello --list-cameras
Available cameras yazısı çıkıyorsa kamera tanındı demektir.

ToF Sensör Bağlantısı

İki VL53L4CD sensörü breadboard üzerinden Pi GPIO'ya bağlanır

⚠️
İki sensörün I2C adresi aynı — bu normal, çözümü var İki VL53L4CD fabrikadan aynı adresle (0x29) çıkar. XSHUT pini ile sırayla açılıp farklı adresler verilir. Bağlantı diyagramındaki XSHUT pinleri kritik.
Pi GPIO → Sensör Bağlantı Diyagramı
─── Pi GPIO Başlığı (40 pin) ───────────────────────────────

Sol taraf Sağ taraf
Pin 1 3.3V ──────────────────────────── SOL ToF VDD
Pin 3 SDA (GPIO2) ─────────────────── SOL ToF SDA ← İKİSİ DE AYNI PİNE
Pin 5 SCL (GPIO3) ─────────────────── SOL ToF SCL ← İKİSİ DE AYNI PİNE
Pin 6 GND ──────────────────────────── SOL ToF GND
Pin 11 GPIO17 ────────────────────── SOL ToF XSHUT ← SADECE SOL

Pin 17 3.3V ──────────────────────────── SAĞ ToF VDD
Pin 3 SDA (GPIO2) ─────────────────── SAĞ ToF SDA ← AYNI PİN (paylaşılır)
Pin 5 SCL (GPIO3) ─────────────────── SAĞ ToF SCL ← AYNI PİN (paylaşılır)
Pin 14 GND ──────────────────────────── SAĞ ToF GND
Pin 13 GPIO27 ────────────────────── SAĞ ToF XSHUT ← SADECE SAĞ

─── Breadboard düzeni ──────────────────────────────────────

Pi Pin 1 (3.3V) ─── breadboard güç rayı (+) ─┬─ SOL ToF VDD
Pi Pin 17 (3.3V) ──────────────────────────────┘
Pi Pin 6 (GND) ─── breadboard güç rayı (-) ─── Her iki ToF GND
Pi Pin 3 (SDA) ─── breadboard orta ─────────── Her iki ToF SDA
Pi Pin 5 (SCL) ─── breadboard orta ─────────── Her iki ToF SCL
Pi Pin 11 (GPIO17) ─ tek kablo ───────────────── SOL ToF XSHUT
Pi Pin 13 (GPIO27) ─ tek kablo ───────────────── SAĞ ToF XSHUT
💡
SDA ve SCL neden paylaşılıyor? I2C protokolü aynı hat üzerinde birden fazla cihaz destekler. Adres farkı olunca Pi istediği cihazla konuşabilir.
🔧
XSHUT neden ayrı? Kod başlarken ikisini de kapatır, sırayla açar, adresini değiştirir. Böylece 0x29 → 0x30 ve 0x31 olur.
✅
Bağlantı doğrulama (PuTTY'de):
sudo i2cdetect -y 1
Sensörler bağlıysa 29 görünür. Kod çalışınca 30 ve 31'e dönüşür.

Arduino Bağlantısı

Pi ve Arduino USB kablosuyla bağlanır — güç + veri tek kablo

Bağlantı Bu Kadar Basit
Raspberry Pi 5 USB-A portu
│
USB kablosu (standart printer kablosu / USB-A → USB-B)
│
Arduino Uno/Mega USB-B portu
Arduino'ya Gönderilen Komutlar
# Pi'den Arduino'ya şu komutlar gönderilir:

"1 90" → Servo 1'i 90 dereceye götür
"2 120" → Servo 2'yi 120 dereceye götür
"3 60" → Servo 3'ü 60 dereceye götür (yaklaşma)
"5 180" → Gripper kapat (servo 5)
"5 0" → Gripper aç
"home" → Tüm servolar başlangıç pozisyonuna
"show" → Arduino mevcut açıları geri gönderir
⚙️
Servo numaraları Arduino kodunuza göre değişir! robot/config_robot.py dosyasında şu satırları kendi robot kolunun servo sıralamasına göre düzenle:
SERVO_BASE = 1 # Yatay dönüş (sol-sağ)
SERVO_SHOULDER = 2 # Omuz (yukarı-aşağı)
SERVO_ELBOW = 3 # Dirsek (ileri-geri yaklaşma)
SERVO_GRIPPER = 5 # Tutucu
✅
Arduino port kontrolü (PuTTY'de):
ls /dev/ttyACM* /dev/ttyUSB*
/dev/ttyACM0 veya /dev/ttyUSB0 görünüyorsa Arduino tanınmış demektir.

Pi Yazılım Kurulumu

PuTTY terminal penceresine sırayla yaz — ~15 dakika

Adım 1 — Sistemi Güncelle
sudo apt update && sudo apt upgrade -y
Adım 2 — Sistem Paketlerini Kur
sudo apt install -y \
    python3-picamera2      # Kamera kütüphanesi
    python3-pip          # Python paket yükleyici
    python3-venv         # Sanal ortam
    python3-smbus        # I2C kütüphanesi
    i2c-tools            # i2cdetect komutu
    libzbar0             # Barkod okuma
    imx500-all           # IMX500 firmware
Adım 3 — I2C'yi Etkinleştir
sudo raspi-config
Açılan menüde:  Interface Options → I2C → Yes (Etkinleştir) → Finish
Adım 4 — Proje Dizinine Geç ve Python Ortamını Kur
# Proje dizinine git
cd /home/pi/ilac-tanima/IlacTanima

# Sanal ortam oluştur (system-site-packages: picamera2 için)
python3 -m venv --system-site-packages venv
source venv/bin/activate

# Python paketleri
pip install --upgrade pip
pip install -r requirements_pi.txt

# ToF sensör kütüphanesi
pip install adafruit-circuitpython-vl53l4cd

# Seri port kütüphanesi (Arduino için)
pip install pyserial
Adım 5 — Kullanıcıya I2C ve Seri Port İzni Ver
sudo usermod -aG i2c,dialout pi
sudo reboot # İzinlerin geçerli olması için yeniden başlat
⏱️
Reboot sonrası Pi 30–40 saniyede açılır. PuTTY'de tekrar bağlan, source venv/bin/activate yaz, sonra testlere geç.

Tam Sistem Çalıştırma

State machine — sistemin adım adım ne yaptığı

python -m robot.main_controller
SEARCHING — Arıyor
Kamera her frame'de "Parol" kutusunu arıyor. Sen kutuyu kameraya tutana kadar bu durumda kalır. Barkod, YOLO veya OCR ile tespit eder.
CENTERING — Merkezleme
Kutu kameranın sağında veya solundaysa base servo (yatay dönüş) küçük adımlarla döner. Kutu kameranın ortasına (%±8 tolerans) gelince bir sonraki aşama.
APPROACHING — Yaklaşma
İki ToF sensörün ortalaması okunur. Hedef mesafe (varsayılan 80mm) dolana kadar elbow servo ileri gider. Her adımda mesafe tekrar kontrol edilir.
ALIGNING — Hizalama
Sol ToF 78mm, Sağ ToF 92mm → robot kutuya eğik bakıyor. Base servo küçük düzeltme yapar, iki değer ±5mm'ye gelene kadar devam eder. En hassas aşama.
GRIPPING — Tutma ✓
Gripper kapatılır, kutu alınır. Robot kol home pozisyonuna döner. Görev tamamlandı.
